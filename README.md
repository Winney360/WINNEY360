## About

I'm a full-stack developer based in Kenya — a student and self-taught engineer with just over a year of consistent, hands-on experience shipping personal and freelance-style projects. My core work is in the **MERN stack**, and I'm increasingly drawn to building **AI-powered applications** that turn everyday friction into something more useful.

I care about clean architecture, considered UI, and software that holds up beyond the demo. I'm comfortable owning a feature end-to-end — from data model to interface — and equally happy collaborating inside an existing codebase.

## Currently Working On

- **Deni Yangu** &middot; Deni Yangu is a credit verification system that helps small traders in Kenya reduce losses by checking and recording customer debt history before issuing goods on credit.
